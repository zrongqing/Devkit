# 服务端技术框架

## 结构

服务端基于 .NET 10 和 ASP.NET Core Minimal API，解决方案入口为 `src/server/Devkit.Server.slnx`。

依赖方向固定为：

```text
Api -> Infrastructure -> Application -> Domain
```

- Domain：实体、值与持久化抽象，不引用 EF Core、Redis 或 ASP.NET Core。
- Application：用例接口和对外 DTO。
- Infrastructure：EF Core、SQL Server、Mapster、Redis、JWT、健康检查和后台任务实现。
- Api：版本化 HTTP 契约、认证中间件、限流、OpenAPI 和 ProblemDetails。

## 已实现能力

- SQL Server EF Core 上下文、迁移与审计拦截器。
- UUIDv7 主键、UTC 审计时间和全局软删除过滤器。
- 用户、角色、refresh token 与 JWT 登录闭环。
- Redis cache-aside 用户资料缓存，故障时回退数据库。
- refresh token 后台清理服务。
- `/health/live`、`/health/ready` 和 `/openapi/v1.json`。
- Dockerfile、Docker Compose、PowerShell 运维脚本。

## 配置来源

ASP.NET Core 按默认优先级加载 `appsettings.json`、环境文件、User Secrets 和环境变量。生产环境不得把密码、JWT 密钥或真实连接串提交到仓库。

主要配置节：

| 配置 | 用途 | 默认行为 |
| --- | --- | --- |
| `ConnectionStrings:Default` | SQL Server 连接串 | 本机 Windows 集成认证示例 |
| `Jwt` | issuer、audience、签名密钥、有效期 | access 15 分钟，refresh 7 天 |
| `Registration:Enabled` | 公开注册开关 | Development 开、Production 关 |
| `BootstrapAccount` | 首个管理员账号 | 默认关闭 |
| `Redis` | 连接串、实例前缀、缓存 TTL | localhost:6379，TTL 5 分钟 |
| `BackgroundJobs:RefreshTokenCleanup` | 后台清理开关与周期 | 开启，每 60 分钟 |

## 基本命令

```powershell
dotnet restore src/server/Devkit.Server.slnx
dotnet build src/server/Devkit.Server.slnx
dotnet test src/server/Devkit.Server.slnx
```

首次运行前必须先设置 JWT 密钥并执行数据库迁移；详细步骤见同目录其他文档。
