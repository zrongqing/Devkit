# 旧合并上下文迁移历史

此目录只保存拆分前的 EF Core 迁移和快照，供审计与旧版本维护，不参与新解决方案构建。

新 Identity、Business 各有独立的初始迁移；禁止将新的初始迁移直接应用到旧合并数据库。现有数据应先备份，再在两个空目标数据库中创建新 schema，停机后使用 `server/scripts/Split-LegacyDatabase.sql` 按上下文复制。该脚本不删除源数据、不复制旧迁移历史，并拒绝覆盖已有目标业务数据。文件对象本体和外部索引不在 SQL 脚本复制范围内。

详见 `server/docs/认证与业务分离部署.md`。升级旧版本的历史数据库请使用对应 Git 版本的原迁移工具，不通过本目录直接运行新应用。
