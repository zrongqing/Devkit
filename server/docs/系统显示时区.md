# 系统显示时区

「系统管理 → 基础参数 → 显示时区」控制 Web 时间戳的展示和日期时间范围筛选。默认跟随浏览器，可设为 `UTC` 或 IANA 地区时区，例如 `Asia/Shanghai`。保存后当前工作台立即生效，其他会话在页面刷新或窗口重新聚焦时读取。业务时间戳仍使用 UTC 存储和传输，Desktop 的现有接口兼容。

| Application 接口 | 授权 | 契约 |
| --- | --- | --- |
| `GET /api/v1/identity/system-settings` | 公开 | `ApiResponse<{ timeZone: string \| null }>`，`Cache-Control: no-store` |
| `PUT /api/v1/identity/system-settings` | Bearer 及 `system.settings.manage`，管理员默认具备 | 必须提交 `{ "timeZone": "Asia/Shanghai" }` 或 `{ "timeZone": null }`，响应同 GET |

`null` 表示跟随浏览器。设置为 UTC 时传 `"UTC"`。无效时区返回 400 `invalid_time_zone`，缺少字段或 JSON 无效返回 400 `invalid_json`。未登录和无权限分别返回 401 和 403。变更与现有管理审计记录在同一次保存中提交。现有日期范围查询契约继续使用 `gte` / `lte`，Web 将输入转换为 UTC 后发送。

部署时先通过 `server/scripts/Update-Database.ps1 -Context Application` 应用 Application 迁移，再发布 Application API 和 Web。迁移只新增 `sys_system_settings` 单例表和一条 `time_zone = NULL` 的初始记录。
