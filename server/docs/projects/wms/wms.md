# 制造业 WMS 系统需求文档

**状态：首版评审稿 · 2026-11-05**　|　[行业术语表](WMS行业术语.md) · [项目协作规则](AGENTS.md)

工厂要能回答三个问题：下一张工单还缺哪些料？发到产线的某批原料用了多少、退了多少？某批成品对应哪些投入批次，剩余库存在哪里？首版围绕这三个问题打通原料仓、线边仓和成品仓的实物账。

## 1. 首版范围与假设

| 范围 | 交付内容 |
| --- | --- |
| 已确认场景 | 制造业仓库，重点为原料管理、生产领退料和成品入库。 |
| P0 首版建议 | 单工厂、自有库存、多仓多库位。采购收货、质量放行、上架、按工单备料与领退料、实际耗用回传、分批成品入库、移库、盘点和批次追溯。用批次管理的离散制造作为验收样例。 |
| P1 候选 | 逐件序列号、包装容器整托作业、波次备料、线边自动补货、成品销售发运和供应商退货。按现场优先级单独评审。 |
| 邻接系统职责 | ERP 负责采购、计划、成本及财务凭证，MES 负责生产执行、报工和实际投料，质量人员或 QMS 负责判定。WMS 记录相应的实物交接、质量状态与库存流水。 |

**待评审的记账假设。** 线边仓纳入 WMS 实物账。车间签收领料时，原料从仓储库位转到指定工单的线边余额。MES 确认实际耗用后，WMS 才扣减这笔线边余额。若现场采用领料即耗用或完工倒冲，需要先改定领退料、对账和追溯的口径，再设计接口。

## 2. 谁负责哪一步

| 角色 | 可执行的动作 | 责任边界 |
| --- | --- | --- |
| 仓库主管 | 授权仓内分派作业、处理短收、批准盘点差异与冲销 | 调账须有原因、原单和独立审批人；不得自审 |
| 收发料员、库管员 | 扫描收货、上架、拣料、交接、移库、盘点 | 限本人获授权的仓库或任务；只能提交实作量 |
| 车间领料员 | 按工单签收、发起退料，核对线边余量 | 限所辖产线和工单；签收数量与实际批次留痕 |
| 质检员 | 按检验单分量放行、隔离或判不合格 | 留存判定人及依据，仓储作业员不可自行放行 |
| 计划员、生产主管 | 下达工单用料需求，批准超计划补料或替代料 | WMS 只执行已批准的工单用料版本 |
| 集成账号、审计员 | 前者交换获准的业务指令和实绩，后者只读查询台账与追溯链 | 均按工厂、仓库和职责限制范围 |

## 3. 从到料到成品的作业要求

| 编号 | 业务动作 | 完成条件与异常处理 |
| --- | --- | --- |
| WMS-01 基础资料 | 维护工厂、仓库、库区、库位、产线、供应商、物料、基本单位、包装换算及批次策略。库位区分收货、存储、线边和隔离用途。 | 例：1 箱 = 12 件。扫描 2 箱记 24 件，保留原单位和当次换算率。缺少换算、批管物料缺批号、停用库位或未知条码时，提示原因并停止过账。 |
| WMS-02 到货接收 | 依据采购订单行或关联该行的到货通知，核对物料、供应商批号、数量与收货库位，允许一行多批、分次接收。 | 确认实收后增加收货位现存量。需检物料标为待检。短收保留未收数量，可由主管注明理由关闭尾数；累计超订购量先拦截，等待上游变更。拒收且未卸入仓库的数量记差异。 |
| WMS-03 质量与上架 | 质检员按批次和数量判定；库管扫描来源与目标库位上架。冻结支持记录批次、涉及数量、原因与解除依据。 | 一批 100 件可放行 95 件、隔离 5 件。仅放行且进入可拣库位的数量可用于新分配。冻结已预留库存时阻断交接，释放受影响预留并提示重配。 |
| WMS-04 工单备料 | 接收已下达的工单、产线、用料行、版本和需料时间。按物料计算需求、净领量、有效预留和缺口，生成备料任务。未结用料行的待分配量 = 批准需求 − 净领量（领料减退料）− 有效预留，最低取零。 | 可按可用量部分预留，剩余显示缺料。效期物料在合格批次中按 FEFO，其他物料按 FIFO；并列时按收货时间、库存明细唯一标识排序。已过期物料不得备料。 |
| WMS-05 生产领料 | 按任务扫码核对库位、物料和批次，记录拣出与交接数量，车间按工单签收。 | 已拣货暂存在备料位，预留随货移动；签收时从备料位转至线边仓、释放相应预留并归属工单。差量留在原任务待补或由主管关尾，错料、错批、超授权量禁止签收。 |
| WMS-06 投料与退料 | 对指定工单、物料、批次接收实际耗用记录；未耗用余料退回时关联原领料行、批次和退料原因。 | 耗用与退料共享同一工单线边余额上限。仓库确认退收后扣减线边并增加退收库位现存；开封或质量待判的余料进入待检，复判放行后可再分配。额外补料、替料须引用批准的变更行。 |
| WMS-07 成品接收 | 按工单完工报告和产出行接收成品，记录成品物料、产出批次、实收数量、班次及目标库位。支持一单多批、同批分次入库。 | 每次接收量受该产出行剩余可收量约束。需检成品先入待检，放行后上架。入库单引用报工及投料凭据；不得因确认入库再次扣减原料。 |
| WMS-08 库内移动 | 同工厂受权范围内按实际搬运量确认移库；记录源、目标、批次与质量状态。 | 对即时交接的两端同时记增减，仓库之间也需双方数据权限。通用移库限未预留、非工单专属的库存；线边料走工单业务。跨厂或需长途在途交接另行立项。 |
| WMS-09 盘点与调整 | 主管按库位创建盲盘任务，确认无进行中的交接后锁定盘点库位，保存账面快照；盘点员录入实数，差异进入复盘和审批。 | 锁定期间阻止对该位的出入、分配与质量变更。差异按物料、批次和质量状态计算；账外发现的批次须核实。若调整后的合格量不足以覆盖已有预留，先重配或释放差额并通知受影响工单。独立审批后过账差额并解锁，无差异直接结案。撤销盘点保留记录并解锁。 |
| WMS-10 台账与追溯 | 可从物料批次查供应商、原始入库、当前位置、相关工单、耗用和产出；从成品批次反查工单及投入。 | 显示每一步的单据行、数量、单位、批次、时间和操作者。MES 提供投入与产出的对应关系时可精确到产出批；仅有工单关联时展示“工单涉及批次”，标明精度。 |

**现场操作入口。** 首版建议提供待收货、待上架、工单备料与交接、生产退料、成品接收和盘点任务清单，以及库存明细、批次履历与异常对账视图。扫码结果须显示识别出的物料、批次、库位和单位，操作人核对数量后提交。键盘录入作为条码损坏时的备用方式，沿用同样的校验并记录录入方式。

## 4. 库存与单据的共同规则

- **库存明细与可用量。** 余额按工厂、仓库、库位、物料、批次、质量状态和基本单位区分；线边料另按工单用料行归属。现存量含待检、合格、隔离与不合格实物。对允许拣料的明细，可用量 = 合格且未过期的现存量 − 有效预留量。收货位、线边工单余料、冻结量和盘点锁定范围不参与新的分配。已在质量状态中排除的数量只排除一次。
- **数量守恒。** 同一批次移库两端数量相等。工单线边余额 = 累计签收领料 − 累计已确认退料 − 累计实际耗用，按冲销后的净额计算。预留只占用可用量。禁止负库存及重复占用，两个任务同时竞争最后一批料时，以服务端成功提交的数量为准。
- **状态按行累计。** 收货行从待收、部分收货到收齐或短收关闭；领料行从待备料、已备料、部分交接到交接完成或关闭余量；成品接收行按实收回写待收、部分收货或收齐。单头汇总行状态，保留计划量、实作量、关闭尾数。工单关闭前核对未完任务、有效预留与线边余料。
- **撤销与更正。** 未过账任务可撤销并释放预留，已拣任务先归位。更正已过账业务时生成关联原流水的反向流水，保留原记录、原因和审批人。被耗用的领料或已出库的收货，须先处理关联业务；遇到数量不足时整笔拒绝。
- **审计与对账。** 每笔过账同时提交单据实绩、余额变化和流水，保留操作时间与业务发生时间。期初余额由经审核的盘点导入形成期初流水。按明细维度汇总期初与期间流水，应与期末余额一致。单位精度由物料定义，不可整除的件数应提示复核。

## 5. ERP、MES 与质量接口的业务边界

以下是待设计的业务交换内容；端点、字段与接口版本在实施时写入服务端契约。

| 业务方向 | 传递的数据 | 对账基准 |
| --- | --- | --- |
| ERP → WMS | 物料、单位、采购行、供应商与订购量；引用稳定外部行号及变更版本 | 同采购行的订购、实收、差异关闭和待收量 |
| MES → WMS | 已下达的工单用料行、BOM 版本、批准的补料或替代、耗用行、报工产出批次；可选投入到产出对应明细 | 同工单用料行的领、耗、退、余；同报工行的产出、实收与待收 |
| 质量人员或 QMS → WMS | 检验单、受检批次、判定数量、结论和版本 | 判定数量合计不超过剩余待检量 |
| WMS → ERP / MES | 分别回传收货、领退料交接、成品接收与冲销实绩，含来源行、批次、基本单位数量和业务凭证号 | 对方按实绩凭证去重；关闭差异时保留处理人和说明 |

同一来源、业务动作与外部实绩行使用稳定标识。网络超时重试应返回首次处理的结果；同标识而数量或批次不同则登记冲突。上游撤改单不得覆盖已过账实绩。缺少前置工单或消费量超过线边余额时，保留失败原因并支持补齐后重试。库存已提交而回传失败时只重发回执。联调前可用带来源凭证的人工录入验证流程，正式接入时按同一来源标识对账。跨模块设计参见 [MES 模块化服务与可靠消息框架](../../MES模块化服务与可靠消息框架.md)。

## 6. 可执行的验收场景

| 场景 | 操作与预期结果 |
| --- | --- |
| A1 · 收货到退料（WMS-01 至 06） | 原料批 R1 实收 100 件，放行上架 95、隔离 5。工单 WO-01 预留 60 后可用 35；签收 60 后线边 60。实际耗用 52、余料 8 退回待检，线边为 0，原料总现存 48，其中可用 35、待检 8、隔离 5。8 件复检放行并上架后可用 43。 |
| A2 · 分批成品与追溯（WMS-07、10） | WO-01 报工产出 F1 共 26 件，分 20、6 两次收齐。两次接收后 F1 现存 26，原料仍为 48。由 F1 可查到 WO-01 和已耗 R1 的 52 件；若同一工单另产 F2 且缺少投料对应关系，应只列工单范围，不能把 52 件全部归给 F1。 |
| A3 · 并发与重放（WMS-04 至 07） | 可用 10 件且无其他限制，两张工单各需 8 件，同时按可用量分配后预留合计 10、未满足数量合计 6。重复发送同一笔退料或成品接收后只产生一次库存变化；同标识改数量须提示冲突。 |
| A4 · 操作拦截（WMS-01 至 08） | 用隔离批次拣料、超出剩余可退量退料、用其他产线身份签收，以及无目标仓权限的移库均被拒绝。核对源位、目标位、单据实绩和预留均保持提交前的数值。 |
| A5 · 盘点与更正（WMS-08、09、10） | 某库位账面 30、实盘 29。冻结盘点期间移出 2 件被拦截。盘点员自审被拒；复盘确认 29 后由主管批准，产生一笔 −1 的差异流水，余额 29，可追溯到原任务并恢复作业。 |
| A6 · 缺料与变更（WMS-04 至 06） | 工单需 A 料 12 件，仅 8 件合格，则可备 8、缺 4。扫入 B 料不得交接。收到工单新版本批准以 4 件 B 替代后，只能按新需求行领用，并保留原 A 料需求与替代依据。 |

## 7. 查询、运行与评审

- **查询和权限验收。** 作业单以单据行、库存以余额明细、履历以流水为分页单位。按时间、工单、物料、批次、库位及质量状态组合查询；同一授权范围适用于列表总数、详情、候选项与追溯。用仅获原料仓权限的账号检查列表与直接访问，越权仓库的数量和单据均不得披露。遵循[统一分页查询](../../统一分页查询.md)。
- **现场指标。** 仓库主管可按工厂、班次与日期统计库存准确率（首次盲盘账实相符明细数 / 首次盲盘明细数）和工单齐套率（截至需料时间已足量备齐或交接的工单数 / 同期到期需备料工单数）。分母为零显示“无样本”。支持点入对应差异或缺料明细。
- **运行验收。** 模拟提交成功后终端断线、服务重启、上游重复投递，验证可查原结果、台账可对平、待回传记录可恢复。上线前按实际峰值单量、扫码并发数和库存明细量测量提交及追溯查询的 P95 耗时；阈值、恢复时限及数据保留期由现场和运维共同确定。

| 评审事项 | 建议确认人 | 将决定的需求 |
| --- | --- | --- |
| 线边库存由谁保管？每次交接能否关联工单、批次？ | 生产主管、仓库主管 | 领料转移时点、退料上限与实际耗用来源 |
| 投料与产出能否逐批对应？是否要求单件序列号或召回？ | 工艺、质量负责人 | 追溯精度与首版验收粒度 |
| 超领、替代、退料复检和有效期截止时点如何判定？ | 计划、质量负责人 | 审批权限、放行条件与 FEFO 候选范围 |
| ERP、MES、QMS 各自维护哪些主数据和单据？是否有执行中的历史工单？ | 各系统负责人 | 对接顺序、期初余额与未完单迁入方案 |
| 现场使用哪些条码、单位和设备？班次高峰及网络条件如何？ | 仓库主管、IT | 扫码识别范围、容量目标及是否需要离线作业 |

## 8. 调研依据与取舍

- ERPNext 的工单区分生产移料、未耗余料退回和分批完工。首版借鉴这三步，并把线边签收与实际耗用分开对账。[GitHub 工单实现](https://github.com/frappe/erpnext/blob/develop/erpnext/manufacturing/doctype/work_order/work_order.py) · [ERPNext 工单作业说明](https://docs.frappe.io/erpnext/work-order)
- OpenBoxes 支持分次收货、暂收后上架。首版用两个时点分别回答“实物到了多少”和“可以拣多少”。[OpenBoxes GitHub 仓库](https://github.com/openboxes/openboxes) · [收货作业](https://help.openboxes.com/article/48-receiving)
- 循环盘点可拆成任务、实盘、差异复核三个步骤。库位锁定是本项目为首版提出的并发策略。[Microsoft 仓储盘点说明](https://learn.microsoft.com/zh-cn/dynamics365/supply-chain/warehousing/cycle-counting)
- 对外物流单元与商品标签采用 GS1 术语。能否识别具体码制、哪些物料必须贴标，留待现场样签确认。[GS1 物流标签指南](https://ref.gs1.org/guidelines/logistic-label/)
